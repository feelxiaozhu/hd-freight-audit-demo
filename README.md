# HD Freight Audit

Web prototype for freight-cost control, warehouse shipment entry and carrier invoice reconciliation.

## Live demo

https://feelxiaozhu.github.io/hd-freight-audit-demo/

## Prototype scope

- Dashboard overview
- Warehouse shipment entry
- Package and pallet configuration
- Carrier management
- Tariffario upload area
- Surcharge management
- Carrier PDF invoice upload area
- Freight-cost reconciliation view
- Exception / discrepancy review
- Company, employee and permission settings

## Intended workflow

1. Warehouse staff enter shipment data.
2. The company configures package sizes, pallets, carriers and agreed tariffs.
3. Monthly surcharge rules are maintained with their effective dates.
4. Carrier PDF invoices are uploaded.
5. The system compares expected freight charges with invoiced charges and highlights discrepancies.

## Current status

This repository contains a **front-end prototype/demo**.  
Database synchronization, user authentication, OCR/PDF parsing and production-grade automatic reconciliation are not yet connected.

## Goal

The goal is to evolve this prototype into a multi-company freight-audit SaaS platform that wholesalers and distributors can configure with their own carriers, tariffs, packaging rules and surcharge structures.
